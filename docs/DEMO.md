# Demo: documented API calls with real outputs

Generated by `python scripts/run_demo.py` against the app with the default settings (`INTERPRETER=rule_based`, `STT_PROVIDER=mock`). Responses are trimmed for reading: the full payload also carries every report field and per-step trace details. All data is synthetic.

Session IDs are random, so they differ between runs.


## 1. Retrieval with an ambiguous name

Two patients are called Priya in this clinic, so the assistant asks instead of guessing. Nothing is opened yet.

